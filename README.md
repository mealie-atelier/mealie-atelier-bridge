Mealie Atelier Bridge is planned as an optional Home Assistant integration for bringing Mealie data into useful kitchen automations. It is a separate project from Atelier Cards: Home Assistant is required for the bridge, but not for the cards.

## Planned direction

- Connect Home Assistant to a Mealie instance with clear, documented setup.
- Make practical recipe and meal-planning workflows easier to automate.
- Explore reliable shopping-list handoffs to services such as Bring, with careful handling of duplicates, checked items and failures.
- Keep credentials protected and request only the access the integration needs.

These are design goals, not capabilities currently available in this repository. Supported services and behavior will be documented only after implementation and testing.

## Project status

This repository is currently an empty project starter. It contains no installable Home Assistant integration, HACS package, automation examples, or verified compatibility information yet. Do not use it to configure a live Home Assistant system. We will publish version requirements, setup steps, permissions and tested examples before the first release.

## Getting started

There is no integration to install yet. A beginner-friendly setup guide and troubleshooting steps will be added when the initial implementation is available.

## Related project

[Mealie Atelier Cards](https://github.com/mealie-atelier/mealie-atelier-cards) is the standalone-first recipe experience. It is intended to work without Home Assistant.
